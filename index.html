n = jumlah seluruh objek, r = jumlah objek yang dipilih. Aplikasi ini menghitung permutasi dan kombinasi standar tanpa pengulangan elemen (0 ≤ r ≤ n ≤ 100). Kolom Item boleh diisi nama sendiri dipisah koma (mis. Ani, Budi, Cici); jika diisi, nilai n mengikuti jumlah item.

Nilai n atau r sudah berubah. Tekan “Hitung!” untuk memperbarui hasil di bawah.
